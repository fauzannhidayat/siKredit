# siKredit

Sistem Pengajuan Pembiayaan Kredit adalah aplikasi web untuk mengelola pengajuan kredit, proses verifikasi, dan persetujuan.

## Features
- Pengajuan pembiayaan kredit
- Manajemen status pengajuan
- Approval oleh petugas/admin

## Tech Stack
- Laravel 13
- PHP
- Blade
- JavaScript
- CSS

## Requirements
- PHP >= 8.4
- Composer
- Node.js
- MySQL/PostgreSQL
- Web server

## Installation
1. Clone repository
2. Run `composer install`
3. Run `npm install`
4. Copy `.env.example` to `.env`
5. Configure the database (recommended: use the provided database.sqlite).
6. Run `php artisan key:generate`
7. Start the app

## Usage
- Submit credit application
- Review application status
